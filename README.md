# 🗺️ DevRoadmaps

### Learn. Build. Grow.

**DevRoadmaps** is an interactive learning platform designed to help developers learn programming languages, frameworks, developer tools, and modern technologies through structured, topic-by-topic roadmaps.

Instead of jumping between disconnected tutorials, follow a clear learning path, understand concepts step by step, practise with examples, and build your development skills at your own pace.

## ✨ What is DevRoadmaps?

Learning a new technology can be overwhelming when resources are scattered across documentation, videos, and tutorials.

DevRoadmaps aims to make that process simpler by organizing learning materials into **clear, connected, and practical learning paths**.

Whether you are starting with programming fundamentals or expanding into modern development tools, DevRoadmaps is being built to help you understand what to learn, in what order, and how to practise it.

## 🚀 Features

- **Structured Learning Paths** — Follow an organized sequence of topics, from fundamentals to more advanced concepts.
- **Interactive Roadmaps** — Explore topics through a connected, visual roadmap experience.
- **Concept-Based Notes** — Learn with concise explanations and structured study notes.
- **Practical Code Examples** — Understand concepts through syntax and runnable examples.
- **Expected Outputs** — See what example programs produce when applicable.
- **Common Mistakes** — Recognize frequent errors and learn how to avoid them.
- **Practice Exercises** — Reinforce your understanding through hands-on practice.
- **Sample Programs** — Review complete programs to connect individual concepts.
- **Developer-Focused Design** — Navigate learning material through a clean, focused interface.

*Feature availability depends on the roadmap and its current implementation.*

## 🧭 Learning Roadmaps

DevRoadmaps is designed to grow beyond a single programming language. The following technologies represent the intended roadmap collection; additional roadmaps will be introduced as their content is developed.

| Category | Planned learning paths |
|---|---|
| Programming Languages | Python, Java, JavaScript |
| Version Control | Git and GitHub |
| Frontend Development | HTML, CSS, React |
| Backend Development | APIs and backend fundamentals |
| Databases | SQL and NoSQL databases |
| Operating Systems | Linux fundamentals |
| Containers | Docker |
| Cloud Computing | Cloud fundamentals and AWS |
| DevOps | CI/CD and deployment workflows |
| Container Orchestration | Kubernetes |

### 📚 How Each Roadmap Is Organized

Where applicable, learning material is organized around:

1. **Fundamentals** — Understand the essential concepts.
2. **Core Concepts** — Learn the syntax, terminology, and underlying principles.
3. **Practical Examples** — Explore code and expected output.
4. **Common Mistakes** — Identify pitfalls and debugging techniques.
5. **Practice Exercises** — Apply what you have learned.
6. **Sample Programs** — Bring multiple concepts together in complete examples.

The exact structure and depth may vary by technology.

## 💻 Run Locally

You can run DevRoadmaps on your own machine to explore the application or contribute improvements.

### Prerequisites

- [Node.js](https://nodejs.org/) — use a version compatible with the project's Vite dependencies.
- npm — included with Node.js.
- Git — to clone the repository.

### 1. Clone the repository

```bash
git clone https://github.com/Ruban-Edward/DevRoadmaps.git
```

### 2. Open the project directory

```bash
cd DevRoadmaps
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to use the application.

### 5. Build for production

```bash
npm run build
```

### 6. Preview the production build

```bash
npm run preview
```

Vite generates the production build in the `dist/` directory.
